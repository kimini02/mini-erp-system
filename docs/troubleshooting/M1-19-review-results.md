# M1 리뷰 7 — 알려진 이슈 상태와 전체 검증

## 증상
KI-02가 해결됨으로 표시됐지만 특근 단건 조회의 부서 범위 문제는 남아 있었다. 추가 리뷰 수정 결과도 알려진 이슈 문서에 반영할 필요가 있었다.

## 재현 방법
기존 특근 단건 조회와 M1 범위 수정 기록을 대조하고, 각 리뷰 항목의 회귀 테스트를 Java 17 + Docker에서 실행했다.

## 원인
목록·승인·반려 경로 해결과 단건 조회의 미해결 상태가 하나의 완료 상태로 묶여 있었다.

## 검토했지만 버린 방법과 이유
이번에 기존 특근 단건 API를 별도로 고치는 방법은 요청한 M2 API 삭제 계획과 범위를 벗어나므로 채택하지 않았다.

## 선택한 방법
KI-02를 “부분 해결 — 특근 단건 조회는 M2에서 기존 API 삭제로 해소”로 정정하고 이번 수정 커밋·테스트·남은 위험을 연결했다.

## 부작용·남은 위험
V2 체크섬이 변경됐다. 로컬 개발 DB V2 적용 여부는 인증 거절로 확인하지 못했다. DB 재생성·Flyway repair는 하지 않았다. 초대 토큰은 발급 이메일 없는 이전 형식이라면 재발송이 필요하다.
