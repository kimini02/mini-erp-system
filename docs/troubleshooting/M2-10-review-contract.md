# M2-10 — 1차 리뷰: 참조·미리보기·휴가 원장

## 증상
참조 역할의 재직자가 없으면 상신이 막혔고, 미리보기에는 종류·부서·참조 목록·상위 부서로 넘긴 이유가 없었다. 상세에 참조가 결재선과 중복되었고, 연도 초과 휴가 및 차감 0일 원장이 허용되었다.

## 재현 방법
Java 17 + Docker에서 `./mvnw -Dtest=M2ReviewTest test`. 수정 전 5개 실행, 5개 실패, 오류·건너뜀 0. 기대 422에 200, 참조 SKIPPED에 ERROR, 0일 원장 기대 0행에 1행을 확인했다.

## 원인
참조도 필수 결재자와 같은 예외 처리를 사용했다. 미리보기·상세 투영이 화면 계약을 다 담지 못했고, 연도/0일 규칙이 처리기에 없었다.

## 검토했지만 버린 방법과 이유
빈 결재자를 전부 건너뛰는 방식은 승인자 공석을 자동 승인으로 바꾸므로 제외했다. 참조자 공석만 건너뛴다. 0일 원장 기록은 회계 효과가 없고 사용 이력을 혼동시켜 제외했다.

## 선택한 방법
참조 공석·기안자 본인은 미리보기에 SKIPPED로 표시하고 스냅샷/알림에서는 제외한다. 필수 결재자 공석은 기존 422를 유지한다. 상세 line은 APPROVER만, references는 참조만 표시한다. skipReason은 SELF/DUPLICATE를 그대로 공개한다. 상신에서 연도 차이를 LEAVE_CROSS_YEAR로 거절한다. 원장에 사람이 읽는 기간·예약 해제 사유를 남기고 0일 행을 쓰지 않는다.

사용자 확정: v1 수치는 이관 실행 연도, memo는 'v1 이관'; 역할 담당자는 users.id 오름차순 첫 재직자. 기존 V3는 변경하지 않았다.

## 부작용·남은 위험
이미 이관된 데이터는 보존한다. 공석인 필수 결재자는 관리자가 지정해야 한다. 날짜 미리 계산도 같은 처리기 규칙을 재사용한다(2차 연차 조회 작업).

## 결과
`./mvnw -Duser.timezone=UTC -Dtest=M2ReviewTest,M2DocumentIntegrationTest test`: 16개 성공, 실패·오류·건너뜀 0. 동시 승인 10회에서 중복 성공 0회, 패한 요청의 추가 알림 0회. 운영/개발 DB는 사용하지 않았다.
