# M2-11 — 사원 선택용 최소 정보 검색

## 증상
일반 사원은 EMPLOYEE V가 없어 /users 목록을 쓸 수 없지만 결재자·인수자를 선택해야 한다.

## 재현 방법
`./mvnw -Duser.timezone=UTC -Dtest=M2LookupTest test`. 일반 사원으로 /users는 403, /users/lookup은 200인지 확인한다.

## 원인
인사 관리 목록과 업무에서 쓰는 사람 선택의 노출 정보·권한이 다르다.

## 검토했지만 버린 방법과 이유
/users 권한을 풀거나 기존 상세 응답을 재사용하면 이메일·역할 등 불필요한 정보가 노출되므로 제외했다.

## 선택한 방법
로그인 전용 GET /users/lookup을 별도 SQL 투영으로 구현했다. ACTIVE만, 부서 완전 일치, 이름 또는 로그인 아이디 앞부분 일치, 이름·id 순서, size 기본 20/최대 100. %와 _는 검색 문자의 뜻대로 이스케이프한다. 응답은 id/name/title/department/departmentId 다섯 필드만 제공한다.

## 부작용·남은 위험
사용자 요청대로 전사 재직자 검색이며 인사 데이터 범위를 적용하지 않는다. 이는 승인된 최소 정보 조회 계약이다. 1 미만·100 초과 size는 400이다.

## 결과
M2LookupTest 1개 통과. 휴직·퇴사 제외, 부서 필터, 이름순, 로그인 아이디 검색, 와일드카드 문자, 민감 필드 부재, 비로그인 401, 일반 인사 목록 403을 확인했다.
