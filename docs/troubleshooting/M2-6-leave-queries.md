# M2-6 — 내 연차 요약·원장·차감 미리 계산

## 증상
옛 잔여 숫자 대신 연도별 원장 합계와 신청 전 차감 일수가 필요하다.

## 재현 방법
`./mvnw -Duser.timezone=UTC -Dtest=M2LeaveQueryTest test`. 같은 컨테이너에서 부여 → 상신 → 승인한 원장, 공휴일·반차·연도 경계를 확인한다.

## 원인
v1 숫자는 예약/해제 이력을 표현하지 못한다. 원장 종류를 먼저 거르고 누적하면 GRANT를 제외한 USE 화면의 잔여가 틀린다.

## 검토했지만 버린 방법과 이유
사용자 응답의 여러 연도 합계를 재사용하지 않았다. 누적 잔여를 Java로 계산하거나 필터된 행끼리만 합산하지 않았다.

## 선택한 방법
요약은 본인·연도별 집계, 원장은 SQL window SUM으로 전체 누적 후 종류 필터와 최신순 정렬을 적용한다. 미리 계산은 상신과 같은 LeaveFormHandler의 일수 규칙을 사용하며 저장하지 않는다. 연도 초과는 error에 확정 메시지를 반환하고 상신은 422 LEAVE_CROSS_YEAR다. 원장 쓰기 API는 없다.

## 부작용·남은 위험
v1 부여·사용은 사용자 확정대로 이관 실행 연도에 귀속된다. 기존 사용자 응답의 연차 호환 숫자는 여러 연도 합계로 유지한다. 자동 부여는 M3 범위다.

## 결과
M2LeaveQueryTest 2개 통과. 10일 부여·1일 사용 후 available=9, reserved=0. USE 행 단독 필터에서도 해당 시점 누적 8을 유지하고 뒤의 RELEASE 행에서 9가 된다. 다른 사원 원장은 보이지 않는다. 공휴일 포함 7일 중 근무일 4/휴일 3, 반차 0.5, 연도 초과 error 및 쓰기 없음 확인.
